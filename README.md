# ACC Setup Guide - AGR UI Redesign

This package contains the redesigned UI files for the ACC Setup Guide only:

- `index.html`
- `style.css`
- `index.js`

The icon paths are intentionally unchanged. Keep your existing `icons/` folder beside these files so the AGR logo and setup-category icons continue to load:

- `icons/AGR_logo_v3.png`
- `icons/tyres.png`
- `icons/mechanical_grip.png`
- `icons/aero.png`
- `icons/electronics.png`
- `icons/damper.png`
- `icons/fuel.png`

No fuel-calculator source files are included in this redesign package.
